# 普通預金システム 移行要件定義書

サンプル銀行（架空）の普通預金バッチを、COBOLからJavaへ移行するための要件定義書である。本書の銀行、業務、数値はすべて研修用に作成した架空のものである。

## 1. 目的

保守要員の確保が難しくなった現行のCOBOLバッチをJavaへ移行する。業務の仕様は変更せず、現行と同等の機能を提供する。

## 2. 対象

| 処理 | 現行プログラム | 頻度 |
|---|---|---|
| 入出金の反映 | `legacy/DEPOSIT.cbl` | 毎営業日の夜間 |
| 利息の計算と記帳 | `legacy/INTEREST.cbl` | 毎月末の夜間 |

### 2.1 口座

- 口座番号は8桁の英数字とする
- 口座種別は次のとおりとする

| 種別 | 内容 |
|---|---|
| 1 | 個人口座 |
| 2 | 法人口座 |

- 口座の状態は、活動中（A）または凍結（F）とする

## 3. 入出金

### 3.1 入金

入金額を残高に加算する。

### 3.2 出金限度額

出金は、1口座につき1日50万円までとする。限度額を超える出金は受け付けず、拒否リストに出力する。

### 3.3 時間外手数料

時間外の出金には、1件につき110円の手数料を徴収する。手数料は全口座に適用する。

### 3.4 残高不足

出金額と手数料の合計が残高を超える場合は、受け付けずに拒否リストに出力する。

### 3.5 凍結口座

凍結口座への入出金は受け付けず、拒否リストに出力する。

### 3.6 口座が存在しない取引

口座マスタに存在しない口座への取引は、拒否リストに出力する。

## 4. 利息

### 4.1 計算方法

月末時点の残高に年利を掛け、当月の日数で日割りして利息額を求める。凍結口座にも利息を付ける。

### 4.2 利率

年利は0.20%とする。

### 4.3 端数処理

利息額の円未満は四捨五入する。

### 4.4 税金

利息額に20.315%の税率を掛けた額を税額とし、円未満は切り捨てる。利息額から税額を差し引いた額を残高に加算する。

## 5. 非機能要件

- 夜間バッチは速やかに完了すること
- 処理結果は監査のために保存すること

## 6. 移行方針

| 項目 | 方針 |
|---|---|
| 言語 | Java 21 |
| データベース | PostgreSQL 16。口座マスタはファイルからテーブルへ移行する |
| 文字コード | UTF-8 |
| 障害時の対応 | 現行どおりとする |
